# Наш трекер 2.0

Общий трекер привычек для двоих. PWA: ставится на iPhone как обычное приложение,
синхронизируется между телефонами мгновенно, работает офлайн, шлёт push-уведомления.

## Что умеет

**Главный экран.** Три вкладки: «Общие», «Мои», привычки партнёра. Закреплённые
привычки — большой карточкой, остальные сеткой по две. На карточке: иконка,
аватарки участников, кнопка отметки, полоска недели и стрик. У каждой привычки
свой цвет.

**Детальный экран.** Стрик и дисциплина, календарь месяца с отметками задним
числом, переключение между своим календарём и календарём партнёра, список
участников с их стриками и кнопкой «Подтолкнуть», меню: изменить, закрепить,
завершить, архив, удалить.

**Режимы привычки.** Каждый день · N раз в неделю (с допуском пропусков) ·
по конкретным дням недели. Необязательная цель (21/30/66/100 дней) — по
достижении приложение предложит завершить привычку.

**Общие и личные.** У общей привычки отмечаются оба, стрик засчитывается за день,
когда отметились обе стороны. Личные видны партнёру только на просмотр.

**Профиль.** Аватарка из галереи, имя, запасное эмодзи, свой цвет, статистика
(активные, завершённые, рекорд, всего отметок, дней в трекере), карта активности
за четыре месяца, история завершённых привычек, архив, достижения.

**Мы.** Сравнение недели, разбивка по дням, сколько общих привычек закрыто вдвоём,
лента событий с реакциями.

**Уведомления.** Напоминания по каждой привычке, «партнёр отметился», «стрик под
угрозой» вечером, подталкивания, итоги недели. Тихие часы.

**Настроение.** В профиле выбирается одно из 12 настроений и пара слов к нему.
Смайлик появляется кружком снизу слева на аватарке и виден партнёру везде.
Сбрасывается через сутки.

**Фотоотчёты и галерея.** К любому дню можно приложить фото и заметку. Все снимки
собираются в галерею с разбивкой по месяцам и фильтром по привычке.

**Баллы и магазин желаний.** 10 баллов за отметку, 100 за достижение. Каждый
заводит список желаний со своей ценой, покупает их за накопленные баллы, а
исполняет партнёр — ему прилетает уведомление.

**Заморозка стрика.** Две заморозки в месяц: день не считается пропуском, стрик
цел. Замороженные дни помечены в календаре.

**Совместные цели.** Общая цель с наградой: «30 дней зала вдвоём → ужин в
ресторане». День засчитывается, только когда отметились оба.

**Экран «Сегодня».** Только то, что осталось на сегодня, с быстрыми отметками и
прогрессом дня.

**Итоги месяца.** Отметки, активные дни, дни вдвоём, фотографии, достижения,
привычка месяца, сравнение по людям. Листается на год назад.

**Год в квадратиках.** Карта активности за весь год в профиле, с переключением
годов.

**Офлайн.** Отметки, сделанные без сети, копятся локально и уезжают в базу, когда
связь появится.

## Настройка

### 1. База данных

Supabase → **SQL Editor → New query** → вставить `supabase/schema.sql` → **Run**.

Скрипт пересоздаёт таблицы, поэтому старые данные удаляются. Он же заводит
хранилище для аватарок и фотоотчётов, права доступа и realtime.

Если база уже была создана более ранней версией — вместо этого прогоните
миграции по порядку: `supabase/migrations/002_mood.sql`, затем
`supabase/migrations/003_features.sql`. Они ничего не удаляют.

### 2. Аккаунты

Вход в приложении — **по логину и паролю**, никакой почты вводить не нужно.
Supabase внутри всё равно хранит адрес, поэтому логину дописывается служебный
домен `@nashtreker.app`. Письма туда не отправляются и отправляться не могут.

**Authentication → Users → Add user → Create new user**:

| Поле | Что вводить |
|---|---|
| Email address | `vlad@nashtreker.app` — логин плюс служебный домен |
| Password | пароль, минимум 6 символов |
| Auto Confirm User | **обязательно включить** |

Повторить для второго человека: `sofia@nashtreker.app`.

В приложении на экране входа вводится только `vlad` — домен подставится сам.
Настоящая почта, если аккаунт был заведён с ней раньше, тоже работает: адрес
со знаком @ уходит как есть.

Затем **Authentication → Sign In / Providers → Email** → выключить
**Allow new users to sign up**.

Профили создаются автоматически, имя берётся из логина. Имя и аватарку каждый
меняет себе сам в разделе «Профиль».

**Пароль** меняется прямо в приложении: Профиль → Сменить пароль. Если пароль
забыт — сбрасывается в панели: Authentication → Users → ⋮ → Reset password.

### 3. Ключи

`public/config.js` — Project URL, publishable key и публичный VAPID-ключ.
Уже заполнено. Секретных значений тут нет: доступ закрывают пароль и RLS.

### 4. Уведомления

Нужны один раз, дальше работает само.

**4.1. Секреты функций.** Supabase → **Edge Functions → Secrets** → добавить:

| Имя | Значение |
|---|---|
| `VAPID_PUBLIC_KEY` | публичный ключ, тот же что в `config.js` |
| `VAPID_PRIVATE_KEY` | приватный ключ (выдан отдельно, в репозиторий не кладём) |
| `VAPID_SUBJECT` | `mailto:ваша@почта` |
| `CRON_SECRET` | любая длинная случайная строка |
| `SERVICE_KEY` | secret key вида `sb_secret_…` из Settings → API Keys |

**4.2. Функции.** Supabase → **Edge Functions → Deploy a new function**,
редактор прямо в браузере:

- `notify` — код из `supabase/functions/notify/index.ts`, **Verify JWT: включено**
- `cron-reminders` — код из `supabase/functions/cron-reminders/index.ts`,
  **Verify JWT: выключено** (защита идёт через `CRON_SECRET`)

Обе используют общий файл `supabase/functions/_shared/push.ts` — его нужно
положить рядом в той же структуре папок.

**4.3. Расписание.** SQL Editor → `supabase/cron.sql`, подставив свой
`CRON_SECRET` вместо заглушки → Run.

**4.4. На телефоне.** Профиль → Уведомления → «Включить». На iPhone это
работает только если приложение открыто **с домашнего экрана**, а не из вкладки
Safari.

### 5. Выкладка

```bash
git push        # репозиторий уже подключён: github.com/undertakeer/nash-treker
```

GitHub → **Settings → Pages → Source: GitHub Actions**. Сборка запускается сама
при каждом пуше в `main`.

Живой адрес: **https://undertakeer.github.io/nash-treker/**

### 6. На айфоны

1. Открыть **https://undertakeer.github.io/nash-treker/** в **Safari**
   (Chrome на iOS ставить на домашний экран не умеет).
2. «Поделиться» → **На экран «Домой»** → Добавить.
3. Запустить с домашнего экрана, войти.
4. Профиль → Уведомления → Включить.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
npm run lint     # линтер, включая правила хуков React
npm run smoke    # проверка: собирается и рисуется без ошибок
npm run check    # линтер и проверка разом — то же, что гоняет GitHub Actions
```

`npm run smoke` собирает приложение, поднимает его в поддельном браузере и
прощёлкивает все экраны и шторки — вход, «Сегодня», «Мы», галерею, магазин,
цели, итоги, профиль, настройки уведомлений и детали привычки. Ловит падения,
из-за которых на телефоне был бы чёрный экран. Запускать перед каждым `git push`.

## Модель данных

- `profiles` — имя, аватарка, цвет, часовой пояс. Заводится триггером при создании аккаунта.
- `habits` — иконка, цвет, тип (общая/личная), режим, напоминание, цель, статус.
- `checkins` — строка есть = день закрыт. Ключ: привычка + человек + день.
- `events` / `reactions` — лента и реакции.
- `achievements` — бейджи за стрики.
- `freezes` — замороженные дни.
- `wishes` / `purchases` — магазин желаний и покупки.
- `goals` — совместные цели с наградой.
- `push_subscriptions`, `notification_prefs`, `notification_log` — уведомления.

## Обновление

Правите файлы → `git push` → GitHub Actions собирает и выкладывает.
На телефонах приложение подхватит новую версию при следующем запуске.

## Место в облаке

Бесплатный тариф Supabase: **1 ГБ** файлов, **500 МБ** базы, **5 ГБ** исходящего
трафика в месяц.

База не забьётся: отметка занимает около сотни байт, вдвоём по десять привычек
ежедневно — примерно 2 МБ в год.

Расходуют место фотоотчёты. Приложение бережёт его само:

- снимок сжимается до 1280px, в WebP где браузер умеет — 120–250 КБ вместо
  нескольких мегабайт с камеры;
- рядом сохраняется миниатюра 400px (20–30 КБ) — сетка галереи грузит её, полный
  файл открывается только при просмотре, трафик падает примерно вдесятеро;
- файлы удаляются из хранилища вместе с фото, снятой отметкой или удалённой
  привычкой — мусор не копится;
- в профиле виден счётчик занятого места и прогноз, на сколько ещё снимков хватит;
- лента событий чистится по расписанию, записи старше 90 дней удаляются.

При таком сжатии 1 ГБ — это около четырёх тысяч фотографий, то есть по одной в
день на двоих примерно пять лет. Когда станет тесно: удалить лишнее прямо в
приложении, либо перейти на Supabase Pro ($25/мес, 100 ГБ).

## Ограничения

- Пуши на iOS работают с 16.4 и только для приложения с домашнего экрана.
- Бесплатный проект Supabase засыпает после недели полного простоя и просыпается
  при первом обращении. Расписание pg_cron ходит каждые 5 минут, так что на
  практике он не спит.
